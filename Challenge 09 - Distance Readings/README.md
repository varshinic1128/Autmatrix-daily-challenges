# Challenge 09 - Distance Readings

## Objective

Measure the distance of an object using an ultrasonic distance sensor.

## Platform

* ESP32
* Wokwi Simulator
* Arduino IDE

## Components Used

* ESP32 Development Board
* Ultrasonic Distance Sensor (HC-SR04)

## Working

The ultrasonic sensor sends ultrasonic waves toward an object and receives the reflected waves.

The ESP32 calculates the distance based on the time taken for the waves to travel to the object and return.

The measured distance is displayed in centimeters.

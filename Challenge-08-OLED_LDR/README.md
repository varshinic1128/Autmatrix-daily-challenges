# Challenge 08 - OLED_LDR

## Objective

Interface an LDR (Light Dependent Resistor) sensor with an OLED display to monitor light intensity.

## Platform

* ESP32
* Wokwi Simulator
* Arduino IDE

## Components Used

* ESP32 Development Board
* LDR Sensor
* OLED Display

## Working

The LDR sensor detects changes in the surrounding light intensity.

The ESP32 reads the sensor value and displays the light-related readings on the OLED screen.

## Wokwi Simulation

https://wokwi.com/projects/477664018439538689

## Output

The OLED display shows the LDR sensor readings during the simulation.

# Challenge 01 - Blink

## Objective

Blink the ESP32's built-in LED at 1-second intervals.

## Platform

* ESP32
* Wokwi Simulator
* Arduino IDE

## Components Used

* ESP32 Development Board
* Built-in LED

## Working

The ESP32 built-in LED is configured as an output.

The LED turns ON for 1 second and then turns OFF for 1 second. This process repeats continuously.

## Wokwi Simulation

[View Wokwi Project](https://wokwi.com/projects/476294518279066625)

## Output

The built-in LED blinks continuously at 1-second intervals.

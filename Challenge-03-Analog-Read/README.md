# Challenge 03 - Analog Read

## Objective

Read the value from a potentiometer and display the reading on the Serial Monitor every 500 milliseconds.

## Platform

- ESP32
- Wokwi Simulator
- Arduino IDE

## Components Used

- ESP32 Development Board
- Potentiometer

## Working

The potentiometer is connected to an analog input pin of the ESP32.

The ESP32 reads the analog value from the potentiometer and prints the value to the Serial Monitor every 500 milliseconds.

As the potentiometer is adjusted, the analog reading changes accordingly.

## Wokwi Simulation

https://wokwi.com/projects/476472188281411585

## Output

The potentiometer's analog value is continuously displayed on the Serial Monitor.

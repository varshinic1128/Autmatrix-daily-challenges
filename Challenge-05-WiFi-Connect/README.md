# Challenge 05 - WiFi Connect

## Objective

Connect the ESP32 to a WiFi network and print its assigned IP address to the Serial Monitor.

## Platform

- ESP32
- Wokwi Simulator
- Arduino IDE

## Components Used

- ESP32 Development Board

## Working

The ESP32 connects to the WiFi network using the WiFi library.

After successfully connecting to the WiFi network, the assigned IP address is displayed on the Serial Monitor.

## Wokwi Simulation

https://wokwi.com/projects/476470887555999745

## Output

The Serial Monitor displays the WiFi connection status and the assigned IP address.

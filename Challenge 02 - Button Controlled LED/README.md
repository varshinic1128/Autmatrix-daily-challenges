# Challenge 02 - Button Controlled LED

## Objective

Read the state of a push-button and toggle an external LED using the ESP32 with basic software debouncing.

## Platform

* ESP32
* Wokwi Simulator
* Arduino IDE

## Components Used

* ESP32 Development Board
* Push Button
* External LED
* Resistor

## Working

The push-button is used as an input and the external LED is used as an output.

When the push-button is pressed, the LED changes its state between ON and OFF.

Basic software debouncing is implemented to prevent unwanted multiple detections caused by the mechanical movement of the push-button.

## Wokwi Simulation

[View Wokwi Project](https://wokwi.com/projects/476294604778215425)

## Output

The external LED toggles between ON and OFF whenever the push-button is pressed.

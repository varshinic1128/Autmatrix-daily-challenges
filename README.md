# Challenge 03 - ESP32 Web LED Control

## Description

This project demonstrates how to control an LED remotely using an ESP32 through a simple web page. The ESP32 hosts a web server with ON and OFF buttons to control the LED.

## Components Required

- ESP32
- LED
- Resistor
- Wi-Fi connection

## Working

1. ESP32 connects to Wi-Fi.
2. ESP32 starts a web server.
3. A web page is hosted by the ESP32.
4. The user opens the web page using the ESP32 IP address.
5. Clicking the LED ON button turns the LED ON.
6. Clicking the LED OFF button turns the LED OFF.

# Challenge 06 - WiFi Connect

## Description

This project demonstrates Wi-Fi connectivity using a microcontroller in the Wokwi simulator.

## Working

1. The microcontroller initializes the Wi-Fi connection.
2. It attempts to connect to the configured Wi-Fi network.
3. The connection status can be checked through the program output.

## Technologies Used

* Arduino C++
* Wi-Fi
* Wokwi Simulator

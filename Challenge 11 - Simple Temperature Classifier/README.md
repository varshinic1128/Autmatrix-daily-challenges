# Challenge 11 - Simple Temperature Classifier

## Objective

Classify temperature readings into different categories using a simple classification program.

## Platform

- Python
- Google Colab / Python

## Technologies Used

- Python
- Conditional Statements

## Working

The program takes a temperature value as input and classifies it into a category based on predefined temperature ranges.

Conditional statements are used to determine the appropriate category for the given temperature.

## Output

The program displays the temperature reading and its corresponding classification.
